# 俳句句会リアルタイムチャットアプリ（静的サイト版）

Phaser.jsとBroadcastChannel APIを使用した、俳句句会のための**GitHub Pages対応**リアルタイムチャットアプリケーションです。

**サーバー不要・npm install不要**で、ブラウザだけで完結します！

## 特徴

✅ **完全静的サイト** - HTML/CSS/JavaScriptのみ
✅ **サーバー不要** - GitHub Pagesで即公開可能
✅ **npm install不要** - ブラウザで直接開けます
✅ **リアルタイム通信** - BroadcastChannel APIで複数タブ間同期
✅ **データ永続化** - ローカルストレージで保存
✅ **スマホ対応** - 横置き推奨レイアウト

## 機能

### ユーザー役割
- **主催者**: 句会を主催し、教室名の設定、披講、句会の終了ができます
- **選者**: 投句作品の選評を行い、披講ができます
- **一般参加者**: 俳句を投句し、チャットに参加できます

### 主な機能
- 🏡 **お庭**: 待機エリア。教室に入る前にここでくつろげます
- 🏫 **教室**: 句会のメインスペース。黒板、教壇、机があります
- 💬 **リアルタイムチャット**: 複数タブ間でリアルタイムにメッセージをやり取り
- 📝 **投句機能**: 一般参加者は俳句を投稿できます
- 📢 **披講機能**: 主催者・選者は句を披講し、黒板に表示できます
- 👤 **呼名機能**: 一般参加者は自分の名前を目立たせて呼ぶことができます
- 💾 **前回のつづき**: ログイン情報を保存し、再入室が簡単（24時間有効）
- 📱 **スマホ対応**: 600px未満のデバイスでは横置き推奨、3:7比率のレイアウト

### キャラクター操作
- **十字キー**: キーボードの矢印キーで移動
- **タップ/クリック**: 画面をタップ/クリックでその場所に移動

### レイアウト

#### デスクトップ
- 左側: 教室/お庭ビュー
- 右側（400px幅）: チャットペイン

#### スマホ（横置き）
- 左30%: 教室/お庭ビュー（縦長）
- 右70%: チャットペイン

#### チャットペインの構成

**一般参加者**:
- チャット欄 (70%)
- 投句欄 (20%)
- ボタン類 (10%): 「教室から出る」「お庭にいく」「呼名する」

**主催者・選者**:
- チャット欄 (40%)
- 披講欄 (10%)
- 投句作品一覧 (40%)
- ボタン類 (10%): 「教室から出る」「お庭にいく」
- 主催者のみ追加: 「句会を終了する」

## 使い方

### ローカルで使う

1. リポジトリをクローンまたはダウンロード
```bash
git clone <repository-url>
cd senku-kukaijo-prototype
```

2. **index.htmlをブラウザで開くだけ！**
```bash
# Macの場合
open index.html

# Windowsの場合
start index.html

# Linuxの場合
xdg-open index.html
```

または、ローカルサーバーを立てる場合：
```bash
# Pythonがある場合
python3 -m http.server 8000

# Node.jsのhttp-serverがある場合
npx http-server
```

### GitHub Pagesで公開

1. このリポジトリをGitHubにプッシュ
2. リポジトリ設定 → Pages → Source を `main` ブランチに設定
3. 公開URLにアクセス！

### 複数人で使う方法

**同じブラウザの複数タブ**で開くと、リアルタイムで同期されます：

1. タブ1: 主催者としてログイン
2. タブ2: 選者としてログイン
3. タブ3: 一般参加者としてログイン

→ 全タブ間でチャット・投句・披講が同期されます！

※ 異なるブラウザや異なるPC間では同期されません（ローカルストレージは各ブラウザ独立のため）

## 開発のポイント

### キャラクター・オブジェクトのサイズ
- キャラクター: 64x64 (通常の4倍)
- 机: 80x60 (4倍)
- 教壇: 160x80 (4倍)
- 黒板: 480x120 (横長に拡大)

### データ保存
全データはブラウザのローカルストレージに保存されます：
- ユーザー情報（24時間保持）
- セッションデータ（ユーザーリスト、教室名）
- メッセージ履歴
- 投句作品
- 黒板表示内容

### リアルタイム同期
BroadcastChannel APIにより、**同じブラウザの異なるタブ間**でリアルタイム同期が可能です。

## トラブルシューティング

**Q: 他のタブで変更が反映されない**
A: 同じブラウザの別タブで開いていることを確認してください。異なるブラウザでは同期されません。

**Q: データが消えてしまった**
A: ブラウザのキャッシュをクリアするとローカルストレージのデータも消えます。

**Q: スマホで横向きにならない**
A: デバイスの画面回転ロックを解除してください。
