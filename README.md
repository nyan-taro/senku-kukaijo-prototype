# 川柳句会場プロトタイプ

レトロゲーム風のオンライン川柳句会アプリケーションです。

## 機能

### ログイン
- **役割選択**: 主催者・選者・一般から選択
  - 主催者: 教室を占有し、句会を管理できます（教室が満室の場合は選択不可）
  - 選者・一般: 空いている教室に参加できます
- **キャラクター選択**: 男性・女性・猫のドット絵キャラクター
  - 16×16ピクセルのレトロゲーム風
  - 4方向（上下左右）の歩行アニメーション

### お庭
- ログイン後、お庭画面に移動します
- 建物が3つあり、それぞれ教室A・B・Cに対応
- 矢印キーでキャラクターを移動
- ドアに近づくと教室に入室できます
- 使用中の教室はグレーで表示されます

### 教室
- **移動**: 矢印キーでキャラクターを操作
- **チャット機能**: リアルタイムで会話
- **投句機能**: 川柳を一行で投稿（改行不可）
- **教壇・机・椅子**: レトロゲーム風のドット絵

### ボタン機能
- **ログアウト**: 最初の画面に戻る（お庭・教室画面から）
- **教室から出る**: お庭に戻る
- **句会を終了する（主催者のみ）**: 教室を開放し、チャットをリセット

### データ保存
- 全ての会話ログと投句ログはlocalStorageに永続保存
- 句会終了後もログは残ります

### スマホ対応
- 画面幅600px以下で自動的にモバイルレイアウトに切り替え
- タブで「チャット」と「教室」を切り替え可能

## 技術スタック

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API（ドット絵描画）
- LocalStorage（データ永続化）

## GitHub Pagesでの公開

このプロジェクトは静的サイトなので、GitHub Pagesで簡単に公開できます：

1. GitHubリポジトリにプッシュ
2. Settings → Pages → Source を `main` ブランチに設定
3. 数分後、URLでアクセス可能になります

## 遊び方

1. 役割とキャラクターを選んで名前を入力
2. お庭で矢印キーを使って建物のドアに移動
3. 教室に入って句会を楽しむ
4. チャットで会話、投句欄で川柳を投稿
5. 主催者は句会終了ボタンで教室を開放
