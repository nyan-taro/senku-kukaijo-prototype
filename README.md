# 俳句句会リアルタイムチャットアプリ

Phaser.jsとSocket.ioを使用した、俳句句会のためのリアルタイムチャットアプリケーションです。

## 機能

### ユーザー役割
- **主催者**: 句会を主催し、教室名の設定、披講、句会の終了ができます
- **選者**: 投句作品の選評を行い、披講ができます
- **一般参加者**: 俳句を投句し、チャットに参加できます

### 主な機能
- 🏡 **お庭**: 待機エリア。教室に入る前にここでくつろげます
- 🏫 **教室**: 句会のメインスペース。黒板、教壇、机があります
- 💬 **リアルタイムチャット**: 参加者全員でリアルタイムにメッセージをやり取り
- 📝 **投句機能**: 一般参加者は俳句を投稿できます
- 📢 **披講機能**: 主催者・選者は句を披講し、黒板に表示できます
- 👤 **呼名機能**: 一般参加者は自分の名前を目立たせて呼ぶことができます
- 💾 **前回のつづき**: ログイン情報を保存し、再入室が簡単
- 📱 **スマホ対応**: 600px未満のデバイスでは横置き推奨、3:7比率のレイアウト

### キャラクター操作
- **十字キー**: キーボードの矢印キーで移動
- **タップ/クリック**: 画面をタップ/クリックでその場所に移動

### レイアウト

#### デスクトップ
- 左側: 教室/お庭ビュー
- 右側: チャットペイン

#### スマホ（横置き）
- 左30%: 教室/お庭ビュー（縦長）
- 右70%: チャットペイン

#### チャットペインの構成

**一般参加者**:
- チャット欄 (70%)
- 投句欄 (20%)
- ボタン類 (10%): 「教室から出る」「お庭にいく」「呼名する」

**主催者・選者**:
- チャット欄 (40%)
- 披講欄 (10%)
- 投句作品一覧 (40%)
- ボタン類 (10%): 「教室から出る」「お庭にいく」
- 主催者のみ追加: 「句会を終了する」

## セットアップ

### 必要なもの
- Node.js (v18以上)
- npm または yarn

### インストール

1. リポジトリをクローン
```bash
git clone <repository-url>
cd senku-kukaijo-prototype
```

2. すべての依存関係をインストール
```bash
npm run install:all
```

### 開発環境での起動

クライアントとサーバーを同時に起動:
```bash
npm run dev
```

または個別に起動:

**クライアントのみ**:
```bash
cd client
npm run dev
```

**サーバーのみ**:
```bash
cd server
npm run dev
```

### アクセス
- クライアント: http://localhost:3000
- サーバー: http://localhost:3001

## 使い方

1. ログイン画面で役割を選択し、名前とキャラクター名を入力
2. 主催者の場合は教室名も入力
3. 「前回のつづき」ボタンで前回の情報を使って再入室可能
4. お庭から「教室に入る」ボタンで教室に移動
5. チャットでコミュニケーション
6. 一般参加者は投句欄から俳句を投稿
7. 主催者・選者は披講ボタンで句を黒板に表示
8. キャラクターを動かして句会を楽しむ

## 開発のポイント

### キャラクター・オブジェクトのサイズ
- キャラクター: 64x64 (通常の4倍)
- 机: 80x60 (4倍)
- 教壇: 160x80 (4倍)
- 黒板: 480x120 (横長に拡大)

### レスポンシブ対応
- 600px未満: スマホレイアウト（横置き、3:7比率）
- 600px以上: デスクトップレイアウト
