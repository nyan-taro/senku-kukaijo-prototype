# 川柳句会システム - ドラクエ風

初期ドラクエ風のバーチャル川柳句会システムのプロトタイプです。

## 特徴

- ドット絵風のレトロなUI
- 教室マップでキャラクターを操作
- 投句・選句・披講の一連の流れを体験
- HTML/CSS/JavaScriptのみで動作（静的サイト）

## 機能

### 一般ユーザー
- ✅ ログイン（ローカルストレージで管理）
- ✅ ドット絵キャラでマップ移動（十字キー/矢印キー/クリック）
- ✅ 40個の椅子への着席システム
- ✅ 投句機能（川柳を投稿）
- ✅ フリーチャット

### 選者ユーザー
- ✅ 投句一覧の閲覧
- ✅ 各句への賞の選択（天・地・人・秀1～5・佳1～30）
- ✅ 披講（入選句の発表）

## 使い方

1. ブラウザで `index.html` を開く
2. 名前を入力し、「いっぱん」または「せんしゃ」を選択
3. 「はじめる」ボタンをクリック

### 操作方法

**移動**
- 十字キー、または矢印キー（↑↓←→）で移動
- マップをクリック/タップして移動
- W/A/S/Dキーでも移動可能

**着席**
- 椅子をクリック/タップして着席
- スペースキーで立ち上がる

**投句（一般ユーザー）**
1. 左ペインの投句欄に川柳を入力（5-7-5形式）
2. 「とうく する」ボタンをクリック

**選句・披講（選者ユーザー）**
1. 投句一覧から各句の賞を選択
2. 「ひこう する」ボタンで入選句を発表

## GitHub Pagesでの公開

このプロジェクトは静的サイトなので、GitHub Pagesで簡単に公開できます。

1. GitHubリポジトリの Settings → Pages
2. Source を "Deploy from a branch" に設定
3. Branch を選択（例：main）
4. Save をクリック
